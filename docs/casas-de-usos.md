# Projeto OrçaFácil — Casos de Uso

## 1. Atores
* **Usuário (Prestador de Serviço):** Profissional autônomo que cadastra materiais, projeta orçamentos e gera os PDFs para seus clientes.
* **Administrador:** Responsável pela gestão da plataforma e manutenção geral.

## 2. Relação de Casos de Uso

| ID | Caso de Uso | Descrição | Escopo |
| :--- | :--- | :--- | :--- |
| **UC001** | Cadastrar Usuário | Permite a criação de conta no sistema. | Futuro |
| **UC002** | Fazer Login | Autenticação para acesso às funcionalidades privadas. | Futuro |
| **UC003** | Gerenciar Clientes | Inserir, listar, editar e remover clientes do prestador. | Futuro |
| **UC004** | Cadastrar Materiais | Registrar itens com nome e custo unitário. | **MVP** |
| **UC005** | Definir Mão de Obra e Lucro | Inserir valor do trabalho executado e percentual de margem. | **MVP** |
| **UC006** | Calcular Orçamento | Processar a soma de materiais, mão de obra e margem de lucro. | **MVP** |
| **UC007** | Gerar PDF do Orçamento | Compilar as informações e permitir o download em PDF. | **MVP** |
| **UC008** | Consultar Histórico | Listar e visualizar orçamentos gerados anteriormente. | Futuro |
