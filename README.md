# 🚀 OrçaFácil

Sistema de precificação e geração de orçamentos em PDF para prestadores de serviços e autônomos.

## 🛠️ Tecnologias
- **Linguagem:** Python 3.12+
- **Framework:** Django 5.x
- **Banco de Dados:** PostgreSQL 16
- **Testes:** pytest
- **Containerização:** Docker & Docker Compose
